# 新居装修管理平台

一个用于自装项目的轻量家装管理工具。纯前端页面 + Python 标准库服务端，无需安装 Python 第三方依赖。

## 功能

- 项目总览、施工阶段、工种准备清单、工艺要求与插座规划
- 收房验房：按类别检查、记录结果和备注、上传现场照片
- 材料进场验收：记录材料品牌型号、数量、供应商、日期、验收结果和照片
- 工长 / 商家通讯录：保存角色、电话、微信、店铺或地址、备注
- 阶段留档：按施工阶段、日期、区域保存照片和备注
- 预算、实际开支、优惠、合同（直接显示合同金额与已付金额，优惠/返现单独列出）、设备选材、量房和备忘
- 默认只读查看，解锁编辑后可修改；同一项目数据同步及附件上传
- 修改记录：按编辑指令用户记录每次变更内容与时间

## 本地使用

在 macOS 上双击 `启动共享.command`，然后在本机浏览器打开 <http://localhost:8777>，默认直接以只读模式查看。需要编辑时点页面右上角“解锁编辑”，输入编辑指令（可编辑指令有两个：`tgh_123`、`lch_123`）；点“退出编辑”会清除编辑会话。离线时只需访问本机地址，不需要互联网。

侧边栏“修改记录”会按指令用户记录谁在何时改了什么（如完成任务、增减预算/开支/合同等），便于回溯。

首次使用需在该项目目录中保留 `启动共享.command` 的可执行权限。若 macOS 阻止打开，可在终端进入项目目录并运行：

```bash
chmod +x "启动共享.command" "启动公网访问.command" "定期备份提交.sh"
```

## 定期自动提交（按当天日期）

`定期备份提交.sh` 会定期检查工作区改动，有变更时执行 `git add` 并以当天日期（如 `2025-11-25`）作为 commit message 提交。双击启动脚本时会自动在后台开启；也可在终端单独运行：

```bash
cd "/Users/tammy/Documents/home/装修管理"
./定期备份提交.sh            # 前台监控（Ctrl+C 停止）
./定期备份提交.sh --daemon   # 后台监控
./定期备份提交.sh --once     # 只提交一次
./定期备份提交.sh --stop     # 停止后台监控
INTERVAL=60 ./定期备份提交.sh --daemon   # 改为每 60 秒检查一次（默认 300 秒）
```

后台日志：`/tmp/zx-auto-commit.log`。

服务进程运行期间，Mac 上可通过 `http://localhost:8777` 访问。关闭启动窗口会停止服务。

## 公网分享（临时网址，一条命令）

1. 首次安装 Cloudflare Tunnel 客户端：`brew install cloudflared`。
2. 双击 `启动公网访问.command`，脚本会自动启动本地服务（如未运行）并创建 HTTPS 公网隧道。
3. 终端会显示 `https://…trycloudflare.com`，把这个网址发给异地的男朋友即可。
4. 对方打开网址后默认只读；需要编辑时点右上角“解锁编辑”并输入编辑指令。
5. 临时网址随隧道停止或重启而变化；公网访问期间请保持启动窗口开着、Mac 开机联网。脚本会自动阻止休眠并在隧道断开后重连（重连后网址可能变化，需把新链接再发给对方）。

打开即为只读，任何人拿到链接都能查看；编辑需要编辑指令。知道编辑指令的人可以修改整个项目，请只分享给可信任的人；不要把含隐私数据的项目暴露在公开渠道。需要更强保护、独立账户或更细的权限时应迁移到正规身份验证方案。

## 数据与备份

- `data/shared-state.json`：服务端项目状态。
- `data/shared-history.json`：修改记录（谁在何时改了什么）。
- `data/uploads/`：验房、材料和阶段照片及开支附件。
- `assets/css/`、`assets/js/`：页面样式与前端脚本（`app.js`、`data.js`）。
- `docs/`：预算表、户型图、准备工作等原始资料。
- `启动共享.command`：启动本地服务。
- `启动公网访问.command`：创建临时公网 HTTPS 隧道。

定期备份整个项目目录，或在页面顶部使用“导出”保存 JSON 数据备份。JSON 备份只包含项目状态；已上传文件也需备份 `data/uploads/` 文件夹。

## 本地开发与检查

使用 Python 3.9 或更新版本：

```bash
python3 -m py_compile server.py
python3 server.py
```

然后打开 <http://localhost:8777>，输入访问指令 `tgh`。日常使用请通过启动器启动。
